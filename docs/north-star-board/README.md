# North Star Board — Meeting Ingest

This directory is the board registry for Meeting Ingest.

- [charter.md](charter.md) — roster, convening triggers, decision standard,
  review history. Authoritative for board procedure in this repo.
- [board-log.md](board-log.md) — records index and obligations table. The
  reconciler (`north-star-board` skill) validates against this file.
- `NNN-slug/` — one directory per convening, immutable once ratified.

The board practice itself is defined by the `north-star-board` skill and the
Orchestration Policy. Registry migrated from the legacy `reviews/` layout on
2026-07-24; see the migration note in charter.md.
